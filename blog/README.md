# Blog de Jobydoo Agency

Collection d'articles SEO rédigés pour positionner jobydooagency.com sur les mots-clé liés à l'agence de communication au Maroc, CRM maroc, marketing digital casablanca, etc.

## Comment publier un article

1. Créer un fichier HTML dans `blog/` avec le HEAD/FOOTER/NAV identique au site (copier depuis `index.html`).
2. Titre H1 = titre de l'article, contenu 800-1500 mots ciblant le mot-clé principal.
3. Ajouter le schema Article dans le `<head>`.
4. Mettre à jour le `sitemap.xml` avec l'URL du nouvel article.
5. Commit + push → Vercel déploie automatiquement.

## Notes de structure

- Chaque article doit avoir son propre `og:image` personnalisé (créer dans assets/img/og-{slug}.jpg).
- Mots-clé à éviter dans le blog : tous les mots-clé Amazon/eBay/dropshipping/abidjan/dakar/hors sujet.
- Liens internes : chaque article doit linker vers {agence-communication.html, crm-sur-mesure.html, creation-site-web.html, media-buying.html} quand c'est pertinent.
- Schéma : utiliser `Article` schema.org dans le `<head>` avec `author` = "Jobydoo Agency".
